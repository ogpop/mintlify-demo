Pricing data is the heart of the Lines API. The `/v2/odds` endpoint returns all four market types — spread, moneyline, totals, and team totals — for every open period of every non-settled event. Like the fixtures endpoint, it supports both snapshot and delta modes: seed your data store with one snapshot call and then poll for incremental updates using the `last` cursor. Delta responses contain only changed periods, not the entire event tree, so your payloads stay small even during high-volume trading windows.

<Note>
  Odds endpoints are subject to a rate limit of **1 request per 2 minutes per endpoint per `sportId`**. Always use the `since` (delta) pattern to stay within this limit. Requests that exceed the rate limit receive a `429 Too Many Requests` response.
</Note>

---

## GET /v2/odds

Returns straight (single-event) odds for all non-settled events in a sport. A period is only included in a delta response when at least one of its markets changed since the `since` cursor — and when it does appear, it carries **all** currently offered markets, not just the changed one.

### Query parameters

<ParamField query="sportId" type="integer" required>
  Sport to retrieve odds for. Obtain valid IDs from `/v2/sports`.
</ParamField>

<ParamField query="leagueIds" type="array of integers" optional>
  Comma-separated league IDs to narrow the response. Pass multiple values as repeated parameters: `leagueIds=2627&leagueIds=218153`. Include all leagues of interest in a single call rather than making separate per-league requests.
</ParamField>

<ParamField query="oddsFormat" type="string" optional>
  Format for returned prices. One of `AMERICAN` (default), `DECIMAL`, `HONGKONG`, `INDONESIAN`, or `MALAY`.
</ParamField>

<ParamField query="since" type="integer" optional>
  Delta cursor. Set to the `last` value from a previous `/v2/odds` response to receive only periods that changed after that point. **Do not** pass `0` or `1`. Omit for a full snapshot. Snapshot responses are cached for up to 60 seconds; delta responses are not cached.
</ParamField>

<ParamField query="isLive" type="boolean" optional>
  Set to `1` to return only live-event odds. Omit to receive both pre-game and live odds.
</ParamField>

<ParamField query="eventIds" type="array of integers" optional>
  Comma-separated event IDs to scope the response to specific events.
</ParamField>

<ParamField query="toCurrencyCode" type="string" optional>
  Three-letter currency code (e.g. `"GBP"`) from `/v2/currencies`. When provided, all bet limits in the response are converted to that currency. Defaults to USD.
</ParamField>

### Example request

<CodeGroup>
```bash cURL (snapshot)
curl -G https://api.pinnacle.com/v2/odds \
  -H "Authorization: Basic U03MyOT23YbzMDc6d3c3O1DQ1" \
  -H "Accept: application/json" \
  --data-urlencode "sportId=29" \
  --data-urlencode "oddsFormat=AMERICAN"
```

```bash cURL (delta)
curl -G https://api.pinnacle.com/v2/odds \
  -H "Authorization: Basic U03MyOT23YbzMDc6d3c3O1DQ1" \
  -H "Accept: application/json" \
  --data-urlencode "sportId=29" \
  --data-urlencode "oddsFormat=AMERICAN" \
  --data-urlencode "since=3301748841"
```
</CodeGroup>

### Max risk calculation

The `maxSpread`, `maxMoneyline`, `maxTotal`, and `maxTeamTotal` fields represent **volume** limits, not risk limits. Convert them to a max risk amount using the decimal price:

```
if price > 2.0:
    maxRisk = maxVolume

if price < 2.0:
    maxRisk = maxVolume / (price - 1)
```

**Example:** `maxMoneyline = 250`, home price = `1.819` (decimal) → `maxRisk = 250 / (1.819 - 1) = 305`.

### Alternate lines

When `altLineId` appears on a spread or total entry, that line is an alternate (non-primary) line. To place a bet on an alternate line, you must supply **both** `lineId` (the period's main line ID) **and** `altLineId` when calling `/v1/line` and the place-bet endpoint. Alternate lines may carry their own `max` volume override that supersedes the period-level limit.

<Tip>
  When a market disappears from a delta response, it means that market is no longer offered for that period — not that it simply didn't change. If `moneyline` is absent in a delta update for a period, remove it from your local copy.
</Tip>

## GET /v1/odds/special

Returns odds for non-settled specials (props and futures). Supports snapshot and delta via the `since` parameter. Each special's contestant has its own `lineId`, `price`, and `max` limit (per-contestant limits are available from April 2024).

### Query parameters

<ParamField query="sportId" type="integer" required>Sport ID.</ParamField>
<ParamField query="leagueIds" type="array of integers" optional>Filter by league.</ParamField>
<ParamField query="since" type="integer" optional>Delta cursor from a previous response.</ParamField>
<ParamField query="oddsFormat" type="string" optional>Price format: `AMERICAN`, `DECIMAL`, `HONGKONG`, `INDONESIAN`, or `MALAY`.</ParamField>
<ParamField query="specialId" type="integer" optional>Retrieve a single special by its ID.</ParamField>

## GET /v1/odds/teaser

Returns spread and total-points odds for a specific teaser. Teaser odds include the adjusted handicap points for each event and leg.

### Query parameters

<ParamField query="teaserId" type="integer" required>
  Teaser group identifier. Retrieve valid IDs from `/v1/teaser/groups`.
</ParamField>

### Response highlights

Each period in the response includes a `spread` object with `homeHdp`, `awayHdp`, and an `altHdp` flag. When `altHdp` is `true`, the event is offered with alternative teaser points that may differ from the teaser group's standard point adjustment.

---

## GET /v1/teaser/groups

Returns all available teaser configurations, including the point spreads offered, the minimum and maximum number of legs, and the payout combinations for each option.

### Query parameters

<ParamField query="oddsFormat" type="string" required>
  Format for returned odds: `AMERICAN`, `DECIMAL`, `HONGKONG`, `INDONESIAN`, or `MALAY`.
</ParamField>
