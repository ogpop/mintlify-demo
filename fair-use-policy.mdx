## Fair usage rules

Pinnacle grants API access on a case-by-case basis. The following rules apply to all users.

<Warning>
  **Commercial use without a written agreement leads to permanent suspension.** Unless Pinnacle has explicitly agreed in writing, any commercial use of the API will result in the permanent suspension of your access.
</Warning>

You must not attempt — or encourage others to attempt — any of the following:

- **Interfere with or disrupt** any API features or services
- **Use the API for commercial purposes** without a prior written agreement with Pinnacle
- **Sell, rent, lease, sublicense, redistribute, or syndicate** the API to any third party without prior written approval from Pinnacle
